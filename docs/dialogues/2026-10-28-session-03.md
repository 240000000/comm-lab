#### AI（判据回复）

```text
先读了任务模式现有的代码，结论是：这套东西能干净地加进去，不用碰三个实验台。

`src/core/metrics.ts` 的 `simulateAwgn` 只接受「符号数」、分母固定是 `symbolCount × 每符号比特`，没法直接表达「我只要前 101 个比特」。所以新题会在新文件里按同一套 `deriveSeed` + 同一条噪声流单独跑一遍仿真，再把「能被每符号比特数整除」的情形与 `simulateAwgn` 逐字段对齐，写成测试。这样既保住 QAM 页的代码路径，也保住「分母严格等于我填的比特数」。

## 判据（6 条主判据 + 1 条边界，点头后照这个验收）

**C1 同参复现，答案现算不写死**
- 同一组参数生成两次，题目对象逐字段相等（真值、种子、符号数、比特数）。
- 参数能被每符号比特数整除时，真值与 `simulateAwgn({order, snrDb, symbolCount, seed: 20261027})` 的 `ber`、`bitErrors` 完全相等。
- 改一个参数（比如 12 → 12.5 dB）真值必须变；代码里没有任何「按参数查表」的答案。

**C2 判分容差，页面上写明**
- 容差取 `max(真值 × 10%, 1e-5)`，闭区间；和现有数值题一样是 ±10%，`1e-5` 只是五位有效数字的绝对底。
- 贴边算对（差 = 容差）、超出一丁点算错（差 = 容差 × 1.0001）。
- 真值为 0 时只认 0（高信噪比、小样本很常见），填 `1e-5` 算错。
- 判分前不显示真值和错位数；判分后才揭晓「仿真答案 + 错了几比特 / 共几比特」。
- 页面上常驻一行：`容差：|你填的 − 仿真值| ≤ max(仿真值 × 10%, 1e-5)；仿真值为 0 时须填 0。`

**C3 非法参数报错，不默默算**
- 阶数 3 / 8 / 256；信噪比 -1 / 20.1 / 30 / NaN；样本量 0 / -5 / 200001 / 1.5 / NaN —— 一律中文报错，不生成、不保存、不进仿真。
- 合法边界照收：0 dB、20 dB、1 比特、200,000 比特（64QAM 下 33,334 个符号，最后一个符号只数前 2 位）。
- 点「生成」就报错在参数区下方，不用等判分。

**C4 存下来的题刷新还在、删了不再出现**
- 判分后可保存；记录含参数、种子、真值、我的答案、对错、保存时间。
- 刷新后列表原样回来；删除只删那一条，刷新后不再出现。
- 本地记录损坏（不是 JSON / 字段缺失）不崩，提示一句「本地记录读不出来，已忽略」；浏览器不让写（隐私模式/配额满）时保存失败有提示，页面其余功能照常。

**C5 声明与零联网**
- 页面常驻三句：题目是你自己挑参数出的、标准答案由本地仿真现算、整个过程不联网。
- 生成 / 判分 / 保存全程 0 个 fetch/XHR（e2e 抓 Network 记录为证）。

**C6 比特账目与跨页一致**
- 分母严格等于输入的比特数 N，不是「符号数 × 每符号比特」；不整除时最后一个符号只数前 r 位。测试用 101 比特 @16QAM（26 个符号），分母必须是 101。
- BPSK 下 `bitCount === N` 且 `SER === BER`。
- 16QAM / 12 dB / 20,000 符号（120,000 比特）与 QAM 页、固定数值题同一条噪声流，真值应为 0.0291375（现算断言，不手抄）。
- 四档在 0–20 dB 内真值都有限、非负、≤ 1。

**C7 边界**
- `git diff --stat` 里不出现 `QamPage.tsx`、`ConvPage.tsx`、`OfdmPage.tsx`；`conv.ts`、`ofdm.ts` 也不动。
- 固定五题的题库与判分一条不改，现有 `tests/missions.test.ts` 全保留；测试只增，126 → 预计 150 左右。

## 两个口径我替你定了

- **样本量按比特填**，上限 200,000；内部按 `ceil(N / 每符号比特)` 跑符号，最后一个符号只算前 r 位。实测 200,000 符号约 18 ms、64QAM 33,334 符号约 7 ms，点一下不会卡。
- **种子固定 20261027、按 SNR 派生**，和 QAM 页同一条噪声流。好处是 16QAM / 12 dB / 20,000 符号的题能在 QAM 页原样复现。
```
