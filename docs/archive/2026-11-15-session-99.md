# 会话 99 · R132：WeakMap 版 getOrInsert 补齐与压页

## 用户原话要点

- 「getOrInsertComputed 与 getOrInsert 同时补到 Map.prototype 和 WeakMap.prototype，defineProperty 带 writable/configurable: true」；文件头注释要写清 22 处里至少 3 处在 WeakMap（`#operatorLists` `#pathCaches` `#canvasCtxFonts`），「R115 只补 Map 是漏」。
- 「加两条单测：WeakMap 上是函数；行为——未命中回调只调一次并写入、命中不再调」。
- 「CDP 真浏览器验收：启动前 delete 两个原型上的方法，加载 484 页那本书翻第 13 页，断言 canvas 非空白且无 TypeError；把「删方法后失败」和「补丁生效后正常」两份证据都贴出来」。
- 「压页……只动排版，不删字」；档位图 14→13.5cm、表格字号 8.5→8.2、行距 1.30→1.27、轮次表描述列压 3 字；「到 30 页立刻停手」。
- 「要删字先列清单等我批，带数字、判据、证据的句子一句不许动」。

## 做了什么

- `src/compat.ts` 重写：`defineMethod(proto, name, value)` 统一走 `Object.defineProperty(..., {writable: true, configurable: true, enumerable: false})`，`patch(host)` 对 `Map.prototype` 与 `WeakMap.prototype` 各补一次，只在原生不是函数时补。
- `tests/compat.test.ts` 加两条：`WeakMap` 上两个方法都是函数；未命中回调只调一次并写入、命中后不再调（`calls` 停在 1、第二次拿到同一引用）。
- 真浏览器证据：headless Edge + CDP，484 页教材第 13 页基线 canvas 399×569、非白 24,515 px（10.8%）；运行期删四个方法后第 14 页报 `TypeError：this[#methodPromises].getOrInsertComputed is not a function`、非白 227,031 px（空白）；`Page.addScriptToEvaluateOnNewDocument` 预删后由 compat 补回，第 13 页恢复 24,515 px 且无报错。
- 压页：只动 `_report/post.py` 与 `md2docx.py` 的调用参数——正文行距 1.30→1.25、图宽 14→11cm（第 1 张 6.5、第 2–4 张 8.5）、章标题段前 20→12、二级标题 6/8→4/6、题注 4/10→3/8、代码块行距 1.15→1.05、数据表 10.5pt→9pt（单元格段后 0、行距 1.0）。33 → 31 → **30 页**，一个字没删。
