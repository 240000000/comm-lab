## 三种过程的生成式与 ρ 的取法
- 采样率固定 fs = 10 kHz，观测时长 T 决定样本数 N = T·fs；种子 `PROC_SEED = 20261111 + kind*977 + T*13 + K*7`。
- 白噪声：逐点 `gauss()`，方差 1。
- 一阶低通：AR(1) `x[n] = ρ·x[n−1] + √(1−ρ²)·w[n]`，`ρ = exp(−1/(τ·fs)) = exp(−1/10) ≈ 0.9048`（τ = 1 ms）；方差稳在 1，相关时间由 ρ 定。σ_T 解析值 `√((1+ρ)/((1−ρ)N))`，等价于 √(2τ/T) 量级。
- 非平稳：每条曲线从各自随机偏置 c 出发，再叠固定斜率漂移 `c + 2·t`（每 100 ms 漂 0.2）加白噪声；集合平均 E[x(t)] = c·t 随时间变，故不平稳，时间平均不认 0。

## σ_T 的解析核对与四个断言实测（固定种子）
| 档 | T=10 ms | T=100 ms | T=1000 ms | 解析（100 ms） |
|---|---|---|---|---|
| 白噪声 | 0.1010 | 0.0356 | 0.0091 | 1/√1000 = 0.0316 |
| 一阶低通 | 0.4275 | 0.1457 | 0.0521 | √((1+ρ)/((1−ρ)N)) = 0.1415 |
| 非平稳 | 0.9657 | 1.1270 | 0.9936 | （不适用，过程不平稳） |
- 断言 1：白噪声 100 ms σ_T = 0.0356，对 0.0316 偏 +12.7%，在 ±15% 内。
- 断言 2：低通 0.1457 / 白噪声 0.0356 = 4.1 倍（≥3 倍成立）；解析比 0.1415/0.0316 = 4.47。
- 断言 3：非平稳带外 92.0%（>90%），σ_T 读数与带外读数都标红，结论改口。
- 断言 4：K=200 白噪声 σ_T(10)/σ_T(100) = 3.195、σ_T(100)/σ_T(1000) = 3.026，√10 = 3.162，两段偏差 +1.0% / −4.3%，都在 15% 内。
- 带外比例按理论的 ±4σ_T 计：白噪声与低通档 0.0%，非平稳 100 ms 档 92.0%。
