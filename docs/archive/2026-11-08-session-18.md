## 三种过程的生成式与 ρ 的取法
- 采样率固定 fs = 10 kHz，观测时长 T 决定样本数 N = T·fs；种子 `PROC_SEED = 20261111 + kind*977 + T*13 + K*7`。
- 白噪声：逐点 `gauss()`，方差 1。
- 一阶低通：AR(1) `x[n] = ρ·x[n−1] + √(1−ρ²)·w[n]`，`ρ = exp(−1/(τ·fs)) = exp(−1/10) ≈ 0.9048`（τ = 1 ms）；方差稳在 1，相关时间由 ρ 定。σ_T 解析值 `√((1+ρ)/((1−ρ)N))`，等价于 √(2τ/T) 量级。
- 非平稳：每条曲线从各自随机偏置 c 出发，再叠固定斜率漂移 `c + 2·t`（每 100 ms 漂 0.2）加白噪声；集合平均 E[x(t)] = c·t 随时间变，故不平稳，时间平均不认 0。

### 这一屏在讲什么

疑问句原样落成标题：「随手抓一条曲线，凭什么代表整个过程？」三个参数：过程类型（白噪声 / 一阶低通 τ=1 ms / 非平稳均值漂移）、观测时长 T（10 ms–1 s 七档对数）、样本条数 K（20–200）。纵轴是「这一条样本的时间平均」，理论统计平均画 0 虚线，上下各一条 ±4σ_T 容许带，带外点换橙色。

σ_T 全部现算、可解析核对：白噪声 `1/√(T·fs)`；一阶低通用 AR(1)（`ρ = exp(−1/(τ·fs)) = 0.9048`），理论 `√((1+ρ)/(1−ρ)/n)`。实测（种子 20261111）：

| 过程 | T=10 ms | T=100 ms | T=1000 ms |
| --- | --- | --- | --- |
| 白噪声实测 σ_T | 0.1010 | 0.0356 | 0.0091 |
| 白噪声理论 1/√(T·fs) | 0.1000 | 0.0316 | 0.0100 |
| 一阶低通实测 | 0.4275 | 0.1457 | 0.0521 |
| 低通 / 白噪声 | 4.2× | 4.6× | 5.7× |

默认档（白噪声、100 ms、100 条）读数 `0.000 / 0.036 / 0.0%`，结论讲各态历经：1000 个独立样本的时间平均标准差只有 0.032，所以 100 条曲线全挤在 0 附近，一条确实能代表整体。

「让它失效」切到非平稳档，读数变成 `0.000 / 1.127 / 92.0%`（后两条标红），结论改口：时间平均能当统计平均用，前提是过程平稳；均值一漂，抓一条算出来的东西只属于那一段时间。

两处踩坑记一下：低通档「收敛更慢」最初拿实测 σ_T 除自己的解析值，恒等于 1.0 倍、什么也没说，改成与**同条件白噪声**比才是 4.6 倍；`CourseChart` 原本只按数据点扫纵轴范围，±4σ_T 虚线被裁到区外，改为把 guides 的 y 一并纳入，顺带给 guide 标签加底色、贴上沿时改放线下方。
