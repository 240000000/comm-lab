## 二、第 8 章：把 α 放进链路
`shootQam` 原来是逐符号独立加噪：每个符号按电平加一个高斯噪声就判决，链路里没有任何滤波器，所以 α 连计算都不会进入。改成先过一遍升余弦成型，再在**固定 0.03T 的采样偏差**上加噪：

```ts
const weight = Array.from({ length: 2 * QAM_ISI_SPAN + 1 }, (_, i) =>
  raisedCosine(i - QAM_ISI_SPAN + QAM_SAMPLE_OFFSET, alpha),
)
```

成型直接复用同文件的 `raisedCosine`（第 743 行），没有另写一个。`QAM_ISI_SPAN = 8`（±8 个码元足够盖住 α=0.05 的旁瓣尾巴），`QAM_SAMPLE_OFFSET = 0.03`。成型本身不引入增益：邻点求和 α=0.05 是 0.999977、α=0.35 是 1.000009。

理论四条曲线一个字没动——它们本来就不含成型滤波，这是「理想理论」与「带成型链路」的对照，不是把理论改到贴合实测。

## 三、第 8 章标定：两条要求不能同时满足
要求是默认档 α=0.35 时实测/理论 ≤1.5 倍、α=0.05 时 ≥5 倍。实测（16QAM、12 dB、ε=0.03T、span 8）：

| α | 实测误码率 | 判错/比特 | 与理论比 |
| --- | --- | --- | --- |
| 0.05 | 5.25e-4 | 42 / 80000 | 3.79 倍 |
| 0.1 | 5.50e-4 | — | 3.97 倍 |
| 0.2 | 5.62e-4 | — | 4.06 倍 |
| 0.35 | 4.50e-4 | 36 / 80000 | 3.25 倍 |
| 0.6 | 4.25e-4 | — | 3.07 倍 |
| 0.9 | 3.87e-4 | — | 2.79 倍 |

理论恒为 1.39e-4。两条要求都差一截，而且**不是 ε 没调好**：

- 扫 ε 得到（α=0.05 / 0.35 的倍数）0.008→1.89/1.89、0.012→1.71/2.07、0.02→2.61/2.52、0.03→3.88/3.25、0.06→22.45/10.37、0.10→150.73/58.78。两档比值始终只差 1.2–2.2 倍，而要求相差 ≥3.3 倍，任何 ε 都拉不开。
- 根因在均方根，不在串扰总和。0.03T 偏移下归一化串扰 `Σ|rc(k+ε)|` 是 α=0.05 为 19.6%、α=0.35 为 8.0%，但决定 BER 的是 `√Σrc²`：0.0523 对 0.0402，折算成 16QAM 电平 `√(5Σh²)` 是 0.1171 对 0.0898，只差 1.3 倍——而 12 dB 的噪声 σ=1/d=0.28 比这两者都大得多，两档都被噪声抬到 3 倍附近。
- 试过双 RC（发端成型 + 收端匹配滤波），方向是反的：rms 变成 α=0.05 为 0.0853、α=0.35 为 0.1644，小 α 反而更小，更不可能满足。

所以 ε 保留用户写死的 0.03，不为了凑数改。第 8 章的交付是「α 已经真的进链路，实测随 α 单调变化 5.62e-4 → 3.87e-4」，而不是「标定通过」。

副作用一条：默认档 α=0.35 的比值 3.25 超过 `computeQam` 里原来的 3 倍 `deviate` 阈值，默认页会带红。把这一处阈值放到 **4.5 倍**（并加注释说明「成型+0.03T 让实测比理想理论高 3–4 倍，4.5 倍才说明链路真坏了」），六档 warn 全部为 false。第 7 章与第 9 章另外两处 `deviate` 仍是 3 倍，没动。

## 四、第 9 章：给选中的波形叠一条接收噪声
`eb/n0` 一档不动——图上画的是无噪声的归一化波形，改了它没有意义。改成给**当前选中的那条**波形叠一条接收端噪声实现：

```ts
const snrDb = 10 * Math.log10(2 * gamma)
const sigma = 10 ** (-snrDb / 20)
```

固定种子 `MATCH_SEED + wave * 17 + round(dt * 100) * 3 + ebn0Db * 7 + 1`。选中那条 `bold: true`（线宽 2.2），另两条 `quiet: true`（透明度 0.18），噪声线是黄色虚线 `接收噪声实现（σ = …）`。默认档 σ=0.282，每条 81 点，读数四条与改前逐字相同（11.0 dB / 0.00 dB / 11.0 dB / 1.91e-4）。

## 五、第 10 章：主图换成量化误差，口径要说清
主图从「原信号 + 零阶保持重建」换成单条量化误差曲线，纵轴固定 ±0.05，series 名按当前位数拼（`量化误差 e(t)（8 bit）`，压扩档再缀「，A 律」）。

口径选择：**只在采样时刻取误差**，`e(t_k) = quantize(cos(2π f_h t_k)) − cos(2π f_h t_k)`，`t_k = k·T_s`，点数就是 `4·fs`（fs=4 → 16 点，fs=8 → 32 点，fs=1 → 4 点）。原因是零阶保持的中段误差属于「保持误差」，默认 fs=4 时能达到 ±1.0，量纲上不是量化误差，塞进 ±0.05 会整条出框。这条口径在回复里也向用户说明。

三个参数都真的动了：`fs` 改点的密度与位置、`bits` 改幅度（8 bit 峰值 3.92e-3、10 bit 9.78e-4、12 bit 2.44e-4，正好 1/4、1/16）、`compand` 改台阶分布。读数三条（混叠误差、量化信噪比、PCM 码率）逐字不变，`docs/tech-report.md:176` 钉的两个数没有被碰。
