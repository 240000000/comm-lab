# R78 · 首页两团粒子在眼图与频谱之间循环变形

## 这一轮要的

上一轮把首页左下角那根描边螺旋线换成了三维眼图瀑布粒子，形态定死在眼图上。这一轮只加一件事：让两团粒子在两种形态之间自动循环变形，另一种形态是三维频谱瀑布。上一轮的粒子化与布局都保留，不推倒重来。

三条硬要求：

1. 新建取点纯函数 `src/labs/spectrumPoints.ts`，给形态 B 的三维点：32 条频谱沿深度等距排开，每条与形态 A 相同列数，横向是频率、纵向是幅度；幅度用升余弦谱（主瓣居中、两侧旁瓣依次衰减），归一化到与眼图同一量级。同一个粒子下标 i 在 A 与 B 里都必须有定义——先把两个形态的点数对齐，再谈变形。
2. 纯函数 reshaper `formAt(elapsedMs) → { from, to, t }`，`from/to` 是 `'eye' | 'spectrum'`，`t` 是 0 到 1 的进度。周期 12 秒：0–4.5 秒停在 eye，4.5–6 秒从 eye 变到 spectrum，6–10.5 秒停在 spectrum，10.5–12 秒变回。`t` 用 smoothstep（3t²−2t³）而不是线性。这个函数必须能单测，六个边界（0、4.499、4.5、6、10.5、12）各断言一次。
3. 改 `src/labs/HomeParticles.tsx`：两套点阵一次性算好、各自存进预分配的 `Float32Array`，逐帧只做「按下标插值 + 投影 + 画点」，不许在循环里 new 任何数组。变形过程中两团照常反向转。`prefers-reduced-motion` 下固定画形态 A 的静态一帧，不要循环。窄屏降级的规则保持不变。

验证要求：三张截图（停在形态 A 的时刻、过渡中点、停在形态 B 的时刻），三个时刻的粒子包围盒与像素数必须明显不同；再确认一次四张卡内芯逐字节不变、13 章读数逐字不变；跑 `npm test` 与 `check:docs` 贴原始输出，测试条数把新增的算进去（290 → 293 起）。

红线：四张卡文案、hero 文案、badge、页脚那句话都不许改；不引入 three.js 或任何 3D 库；投影与深度排序都手写。

## 一、形态 B 的取点：`src/labs/spectrumPoints.ts`

为什么不另起一套网格：变形的前提是「第 i 个粒子在 A 与 B 里都有位置」，所以 B 直接复用眼图那张网格——`SPECTRUM_TRACES = EYE_TRACES`（60 条）、`SPECTRUM_SAMPLES = EYE_SAMPLES`（100 列）、`SPECTRUM_SPAN = EYE_SPAN`（深度 ±0.7）。每条谱线就是原来一条迹，每列就是原来一个采样点，`x` 与 `z` 与眼图逐点相同，只有 `y` 从「码元叠加后的幅度」换成「该频率上的谱幅度」。

谱形状取 `spectrumAmplitude(f) = sinc(f) · exp(-(f/3)²)`：`sinc` 给升余弦谱的主瓣与交替衰减的旁瓣，那个高斯项只是把远端旁瓣再压一点，免得最深处的谱线比近处还密。实测：

- `f = 0 / 0.5 / 1 / 1.5 / 2 / 2.5 / 3 / 3.5` → `1.0000 / 0.6192 / 0.0000 / −0.1653 / −0.0000 / 0.0636 / 0.0000 / −0.0233`，零点落在整数上、旁瓣正负交替且依次衰减。
- 整片幅度 `maxAbs = 0.9977`、最小 `−0.1736`，和眼图的 ±1.6193 摆幅是同一量级，B 不会比 A 高出一截。
- 两套点阵都是 6000 点、`Float32Array` 长度都是 18000，`spectrumPointCount() === eyePointCount()`。

## 二、形态循环：`src/labs/formCycle.ts`

```ts
formAt(elapsedMs): { from: 'eye' | 'spectrum'; to: 'eye' | 'spectrum'; t: number }
```

四段：停 A（0–4.5 s）、A→B（4.5–6 s）、停 B（6–10.5 s）、B→A（10.5–12 s）。`t` 只在两段变形里有意义，停住时返回 `{ from: x, to: x, t: 0 }`。进度走 `smoothstep(u) = u²(3−2u)`，两端导数为零，起止不会被「拽住」。负时间与超过一轮的时间按 `((ms % 12000) + 12000) % 12000` 回绕。

边界实测（探针 + 单测）：`0` 与 `4499` → `eye-eye-0`；`4500` → `eye→spectrum, t=0`；`5999` → `t ≈ 0.9999987`；`6000` → `spectrum-spectrum-0`；`10500` → `spectrum→eye, t=0`；`12000` → `eye-eye-0`；`13500` 与 `1500` 同态。

## 三、`HomeParticles.tsx`：两套点阵，逐帧只插值

- 两套点阵在 `useEffect` 里各算一次：`eye = eyePoints()`、`spectrum = spectrumPoints()`，同一个下标 `at = (trace * EYE_SAMPLES + sample) * 3`。
- 逐帧只做：取 `formAt(elapsed)` → 对每个粒子 `y = yEye + (ySpectrum − yEye) * t`（`t` 为 0 时完全走原路径，B 段 `x`/`z` 与 A 相同，所以横向与深度的投影照旧）→ 旋转投影 → 分 12 档深度画 `fillRect`。循环里没有任何 `new`，`sx`/`sy`/`halfSize`/`bucket` 都是挂载时预分配的 `Float32Array`/`Uint8Array`。
- 两团的反向旋转与上一轮一致（`zone 0` 顺时针、`zone 1` 逆时针 + π），变形期间照常转，所以过渡中点两团都在动。
- `prefers-reduced-motion: reduce` 时只调一次 `draw(0)`，`t` 恒为 0，画的是形态 A 的静态一帧。
- 窄屏规则未动：窗口 < 1280 时隔四列取点，总数仍 ≤ 3000。
