改后：

```python
# 提交号与日期取 tag 所指的那个 commit，不取 HEAD：补 archive 提交后 HEAD 会往前挪一格，封面就会印出比 tag 更新的提交号。
_tag = _sp.run(["git","-C",_repo,"describe","--tags","--abbrev=0"],capture_output=True,text=True).stdout.strip()
_sha = _sp.run(["git","-C",_repo,"rev-list","-n","1",_tag],capture_output=True,text=True).stdout.strip()[:7]
_date = _sp.run(["git","-C",_repo,"log","-1","--format=%ad","--date=format:%Y-%m-%d",_tag],capture_output=True,text=True).stdout.strip()
out.append(f"§M§对应提交　{_sha}（tag {_tag}）　　日期　{_date}")
```

两个错各自对应一处改动：提交号从「HEAD」换成「`rev-list -n 1 <tag>`」，日期从常量换成「该 commit 的 `%ad`」。`git rev-list -n 1` 给的是完整 sha，按 7 位截短后与原来 `%h` 的观感一致。
