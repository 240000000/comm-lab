# 2026-11-10 · 第 46 段 · R70（首页左下角改成竖螺旋条带）

## 这一轮要做什么（要求原文要点）

1. 尺寸由留白宽度算，不许写字面常量：留白宽 = `(100vw − min(1080px, 100vw − 48px)) / 2`（1440 → 180、1920 → 420）；曲线宽 = 留白宽 − 24 再 `clamp(120px, …, 300px)`；高 `min(56vh, 520px)`；锚 `left:0; bottom:0`。任何 ≥1280 宽度都要恰好躺在留白里，一个像素也不进卡片区域，不许靠 mask 遮丑。
2. 形状改成绕竖轴的螺旋线：点在 `(R·cosθ, y(t), R·sinθ)` 上取，`y` 自上而下均匀推进，整体绕竖轴缓慢自转；竖容器配竖向缠绕，条带被填满。取点仍是 `curvePoints.ts` 的纯函数、时间到角度仍只有一个入口；现有 4 条断言必须继续通过，再补两条：半径在整个参数区间恒定（±1e-9）、相邻两圈高度差为常数。
3. 提亮：`opacity` 到 0.65 左右，描边加一条低透明度同色外发光；颜色不要用右上角星座那套青色，换偏紫或偏暖；mask 只保留右侧 8% 的柔和收边（不许再 56%）。
4. `<1280` 仍 `opacity: 0`；`prefers-reduced-motion` 仍只画一帧；位图分配仍只走 `canvasSize.ts` 的 `syncCanvasSize`。
5. 红线：首页四张卡文案一字不动、hero 与 CTA 不动、13 章 compute 与读数一行不动、章名保持 R69 的全称。
6. 验收：四条命令贴原始输出；1440×900 与 1920×1080 各截一张首页全图，另按留白矩形裁「曲线自带包围盒」一张；再对四张卡片逐张截图，与 R69 同尺寸截图逐字节比较必须 `identical: true`。
7. 汇报：报人时；回答曲线包围盒右缘与卡片左缘的像素差。

## 代码怎么改的

### `src/labs/curvePoints.ts`——从三瓣横曲线改成等半径竖螺旋

| 常量 | 值 | 作用 |
| --- | --- | --- |
| `SPIRAL_TURNS` | 7 | 竖直方向缠 7 圈，条带被填满 |
| `SPIRAL_RADIUS` | 1 | 半径恒定，透视下近大远小只由深度项决定 |
| `SPIRAL_SPAN` | 1.4 | 从 `u=0` 到 `u=1` 的竖直总落程 |
| `CURVE_SAMPLES` | 900 | 采样数，7 圈 900 点，足够顺滑 |

```ts
export function curveRadius(_u: number): number {
  return SPIRAL_RADIUS
}

export function curveHeight(u: number): number {
  return (0.5 - u) * SPIRAL_SPAN
}

export function homeCurvePoint(u: number, phase: number): CurvePoint {
  const turn = u * TAU * SPIRAL_TURNS + phase
  return {
    x: SPIRAL_RADIUS * Math.cos(turn),
    y: curveHeight(u),
    z: SPIRAL_RADIUS * Math.sin(turn),
  }
}
```

`pointLength` 从「三维模长」改成「到竖轴的距离」（`Math.hypot(x, z)`），这样「半径恒定」这条断言才有意义。`phaseAt` 没动，时间到角度仍然只有一个入口。

### `tests/curvePoints.test.ts`——6 条

R69 的第②条断言写的是「参数走满一圈回到起点，曲线是闭合的」。螺旋不是闭合曲线，`u=1` 的 `y` 必然比 `u=0` 低一个 `SPIRAL_SPAN`，所以这条按新的形态改成「水平投影回到起点 + 竖直正好落满 SPAN」——首尾的 `x`、`z` 仍然逐位相等（转过整数圈），只是不再要求三维重合。其余三条原样通过，另加两条新断言：

| # | 断言 | 结果 |
| --- | --- | --- |
| 1 | 221…901 个采样点坐标全有限、`0.2 < pointLength < 2` | 通过 |
| 2 | `u=0` 与 `u=1` 的 `x`/`z` 差 < 1e-12，`y` 差 = `SPIRAL_SPAN`；点数 = `CURVE_SAMPLES + 1` | 通过 |
| 3 | 相位只转角度：模长差 < 1e-9、`y` 不变、相位 π 时 `x`/`z` 反号 | 通过 |
| 4 | `phaseAt` 线性：0 / π / 2π / 自定义周期 | 通过 |
| 5 | **新增**：0..1 上千采样，半径恒为 `SPIRAL_RADIUS`，误差 < 1e-9 | 通过 |
| 6 | **新增**：相邻两圈高度差恒为 `SPIRAL_SPAN / SPIRAL_TURNS`，误差 < 1e-12 | 通过 |

### `src/labs/HomeCurve.tsx`——投影、外发光、配色

- 配色从青色换成偏紫 `VIOLET = '176, 148, 255'`，与右上角星座的 `60, 227, 198` 明确区分。
- 投影：`TILT = 0.5`、`FOCUS = 3.6`；`unitX = width * 0.4 / SPIRAL_RADIUS`、`unitY = (height * 0.46) / (SPIRAL_SPAN / 2)`、`depth = FOCUS / (FOCUS + z * 0.6)`，屏幕坐标 `x = width/2 + x * unitX * depth`、`y = height/2 - (y * unitY - z * unitX * TILT)`。
- 描边分两层：先画 3.4 px、alpha `0.05 + 0.09 * near` 的同色外发光，再画 `1.0 + 0.8 * near` px、alpha `0.24 + 0.58 * near` 的主描边，`near` 由深度归一化得到，近处的圈更亮更粗。
- 其余约束没动：`syncCanvasSize` 管位图分配（返回 true 才 `setTransform`）、`ResizeObserver` 观察尺寸、`window.innerWidth < 1280` 不画、`prefers-reduced-motion` 只 `draw(0)` 一帧、卸载时 `cancelAnimationFrame`。
