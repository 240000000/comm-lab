## 单极性模型的幅度与门限怎么定的

- 约定采样器噪声 σ = 1，即 N0 = 2。比特能量 Eb 与峰值幅度 A 的关系是 Eb = A²/2，所以 A = √(2Eb)。
- 每比特信噪比 γ = Eb/N0 = Eb/2，于是 Eb = 2γ，A = 2√γ。相位误差按 cos²φ 折到有效能量上：A = 2√(γ·cos²φ)。
- 单极性 OOK 的判决门限取在 A/2 = √(γ·cos²φ)；门限两侧噪声标准差都是 1，错判概率 Q((A/2)/1) = Q(√(γ·cos²φ))，与理论式同形。
- 双极性（2PSK）同一套 σ=1、N0=2 下峰值是 ±√(2γ)，门限 0，错判概率 Q(√(2γ·cos²φ))，比 2ASK 少 3 dB——这就是「2ASK 白丢 3 dB」的来源：单极性平均每比特能量只有峰值幅度那一半。
