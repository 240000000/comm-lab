## 判据里被否掉或改掉的

- 「共用文档被提前销毁」是最可能的假设，实测被否：销毁只发生在清原件（`clearPdf → closeBook`），扫描链的清理不会碰 doc。
- 「先跑一遍扫描，再开书栏」这条路径复现不出空白，反而证明两处共用同一份 doc 是好事。
- 用 `document.querySelector('.shelf-pick')` 点「进入」会点到默认书那一行，课程视图仍是内置书，`waitFor('aside')` 超时；改成按 `aria-label` 里含「樊昌信」挑按钮。
- 页面内 `indexedDB.deleteDatabase` 返回 `blocked`（页面占着连接），清库要走 UI 的 `.shelf-drop`。
- 本机模型无图像输入能力（`read_image` 与 `modlens_read_image` 都不可用），截图内容只能靠 canvas 像素统计间接验证，这是本轮验收的局限，已如实记录。
