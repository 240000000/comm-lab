## 四、卡在哪

1. **第 5 章 FM 失真一开始是 6.1%。** 原因：鉴频把相位序列当成有半样本延迟，先减了半样本再算中心差分，输出整体滞后半个样本，对齐后仍留着斜率差不齐。改法：`demod = phase.map((_, i) => 中心差分)`，不再手动补延迟，失真回到 0.0%。
2. **第 5 章 SSB 带宽 0.50 kHz 对不上理论 1.50 kHz。** 原因不是代码错，是双音消息只覆盖 1–1.5 kHz，单边带搬移后只剩 0.5 kHz。判据里写的理论值按消息最高频率 1.5 kHz 算，页面读数因此比理论窄——这一条按「读数写清口径」处理，读数保留实测，说明写「消息覆盖 1–1.5 kHz」。
3. **第 10 章量化信噪比差 0.13 dB。** 用 1,024 个采样点统计，相位栅格不够密会带 0.3 dB 上下的取样偏差；改成 8,192 点相位网格重新统计，差 0.13 dB，落在 0.2 dB 阈值内。
4. **截图整页空白。** `vite preview` 对 `/comm-lab/assets/*.js` 这类不存在的路径走 SPA 回退，返回 `text/html`，headless Edge 拿到 MIME 不对的模块脚本直接不执行。改法：把构建产物复制成 `D:\harness\tmp\site\comm-lab\`，用 `python -m http.server 8000` 普通静态服务起在 `D:\harness\tmp\site`，再截 `http://localhost:8000/comm-lab/#/course?no=N`。
5. **测试数从 171 增到 182 之后，`docs/tech-report.md`、`docs/preview.md`、`README.md` 里手写的 171 全部要跟着改。** 这些数字本轮已全部改成 182，并且由 `check:docs` 盯着，下一次再变会直接报行号。
