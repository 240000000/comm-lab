## 这一轮要解决什么

R122 结束时，模型模式虽然走的是图片直传，但 `readImage` 仍先跑一遍本机 tesseract：OCR 慢了，用户就要多等一次；OCR 认错了，进程还会按错的题面走。R123 把这层拿掉——有端点时模型自己看图、自己给题面与章节，OCR 只留给离线模式。

顺带补上 tag：R122 打在 `5a9e69f`，而端点配置是后一个提交 `ac2d81f` 引进来的，所以 R122 那一版打开时还没有端点。R123 指向同时含代码与配置的提交。

## 做了什么

- `src/labs/SolvePage.tsx`
  - 模块级 `const nowMs = () => performance.now()`：组件体内直接读时钟会被 `react(purity)` 规则拦下（3 条 warning），提到模块级就不算渲染副作用。

    - `error`：落错误态，返回 `true`——由调用方直接结束，不再走 OCR，也不回退成演示答案。
    - `offline`：返回 `false`，交回原来的 OCR 链路，那一段一个字没改。
  - `readImage` 在清空上一次状态之后加一道分流：`if (wired === true) { const handled = await askModelFirst(blob, label); if (handled) return }`。
  - 卡 2 的「原始识别」折叠只在 `transcript && text && text !== transcript` 时出现（模型模式没有本机 OCR 文本，自然不出现）。
