# 2026-11-14 · session 86 · R117 答题模式骨架：上传截图、定位章节、离线三题

## 用户原话（要点）

R117 只做答题模式的骨架与离线三题，不接真模型。「这一轮不碰首页四卡、不碰 13 章 compute。」新路由 `#/solve`，入口加在扩展模式的入口区（书架、功能模块之外新增一块），文案「答题模式 · 上传题目截图」。

布局两栏：左栏放题目与答案（上传区 → 识别出的题面 → 答案卡 → 关键步骤），右栏用 iframe 嵌 `${location.origin}${location.pathname}#/course?no=N`，这一轮只做「自动打开对应章节」，把参数摆进滑块留给 R118，因为「那需要 CoursePage 支持 URL 传参，风险大」。

识别复用 `src/course/ocr.ts` 的 worker 创建逻辑，抽一个能吃图片的入口；不要把同一套 worker 配置再写一遍。定位复用 `src/course/concepts.ts` 的 `scoreSection`，拿 Top1 的 topicId 决定打开第几章，左栏显示「已定位到第 N 章 · 命中词：…」，命中不明显时给 Top3 让人自己挑。

模型层只写接口与被禁用的默认实现：`src/answer/provider.ts` 导出 `AnswerProvider`、`AnswerResult`、`defaultProvider`；没有配 endpoint 就返回 `{ status: 'offline' }`，UI 必须明确写「演示模式：未接模型，下面是从内置题库取的答案」，不许假装是模型答的。

内置三题离线可演示、答案硬编码且必须算对：求信道容量、求 2PSK 达到某误码率所需的 Eb/N0、求 m 序列周期。三题都要有截图样本、标准答案、推导步骤与章节号，数值必须在测试里用 `src/core/course.ts` 的既有函数复算，不许手抄。

边界：不写 localStorage 存 key、不把任何 key 写进仓库、不引新依赖、不动 `src/core/course.ts` 的数据、不动首页四卡与 hero、提交说明里的数字照旧由 check:docs 现算。

## 这一轮要解决什么

首页四张卡是省赛评委第一眼看到的东西，已经冻结；答题模式是新入口，只能长在扩展模式里。难点是「没有模型也要能演」：识别必须是真的 OCR（不能假装认得），答案必须是本机算得出的数（不能编），定位必须能说清凭哪几个词定的章。三者缺一个，演示就成了空壳。

## 这一轮做了什么

- `src/router.ts`：`Route` 加 `'solve'`，`parseHash` 认 `/solve`。
- `src/App.tsx`：`#/solve` 分发到 `SolvePage`；扩展模式里在 `ModulePanel` 之后加 `home-extra-block`，内含 `<a className="solve-entry" href="#/solve">`（主文案「答题模式 · 上传题目截图」）。首页四卡与 hero 一字未改。
- `src/answer/provider.ts`：`AnswerParam`、`AnswerResult`、`AnswerOffline`、`AnswerProvider`；`endpoint()` 读 `import.meta.env.VITE_ANSWER_ENDPOINT`（Node 下没有 env 时返回空串），`remoteProvider` 无端点直接 `{ status: 'offline' }`，`hasModelEndpoint()` 供 UI 判断。
- `src/answer/bank.ts`：三题 `capacity`（ch04）、`psk-ebn0`（ch07）、`mseq-period`（ch12），各带题目原文、样本图路径、标准答案与推导步骤。
- `src/answer/locate.ts`：`locateProblem(text)` 走 `scoreSection`，`MIN_SCORE=3`、`MIN_MARGIN=2`，分数或分差不够就标 `ambiguous`，命中词取前 6。
- `src/course/ocrImage.ts`：`recognizeImage(blob)` 复用 `createOcrWorker`（动态 import，避免把懒加载的 pdf.js 链路拉进主包），带 90 s 超时，返回 `{ ok, text, ms }` 或 `{ ok: false, message }`。
- `src/labs/SolvePage.tsx` + `solve-page.css`：两栏，左栏四卡（上传 / 识别出的题面 / 答案 / 关键步骤），右栏 iframe 指 `#/course?no=N`；答案卡顶部徽标按 `hasModelEndpoint()` 显示「模型作答」或「演示模式：未接模型，下面是从内置题库取的答案」；模糊时给 Top3 手选。
- `public/answer-samples/{capacity,psk-ebn0,mseq-period}.png`：三张题目截图样本，780×111 @2x。
- `tests/answer.test.ts`：6 条——三题数值用 `channelCapacity`、`qFunction`、`chapterByNo(12).compute` 复算，`locateProblem` 把三题落到 4/7/12 章，`chapterFromTopic` 解析，模糊题面标 `ambiguous`，无端点时 `defaultProvider` 返回 offline 而不是抛错。
