# 2026-11-12 · R97 图表轮：横轴换 C/N、两条阶梯回来、两个周期

## 一、这轮要解决什么

上一轮（R95）给第 8 章加了「升余弦成型 + 固定 0.03T 采样偏差」，想让滚降系数 α 动起来。方向是错的：滚降系数不改变理想误码率，它改变的是占用带宽，所以拿人造 ISI 去换 α 的可见性是拿错误换可见。这一轮把那段拆掉，改成横轴换 C/N——同一带宽下的载噪比，`C/N = Eb/N0 · log2(M)/(1+α)`，每条曲线按 `10log10(log2(M)/(1+α))` 平移，α 一拖整族曲线平移，而且四档星座位移各不相同。

另外五件事一起做：第 10 章恢复两条阶梯（上一轮换成了量化误差单曲线，用户否掉）、第 12 章画两个周期好数清两根顶到 1 的杆、第 9 章给折线改名、第 3 章空序列不进图例、第 13 章参数补默认值。

## 二、第 8 章：撤掉人造 ISI，横轴换 C/N

删掉 `QAM_ISI_SPAN` 与 `QAM_SAMPLE_OFFSET` 两个常量和整段成型卷积，`shootQam(order, ebn0Db)` 回到逐符号独立加噪——和本轮之前（R94 及以前）的噪声口径一致，所以实测点回到 1.08 倍附近。

`computeQam` 里新增：

```ts
const shiftDb = 10 * Math.log10(k / (1 + alpha));
```

四条理论曲线的横坐标改成 `i + 10*Math.log10(log2(value)/(1+alpha))`，实测点的横坐标改成 `ebn0Db + shiftDb`，`xLabel` 改成 `C/N（dB）`，判据从 4.5 倍改回 3 倍（那是为了容纳人造 ISI 才放宽的）。

读数口径不动，仍按 Eb/N0 报：`谱效率 / 理论误码率 / 实测误码率`，默认档三个数逐字未变（1.39e-4 / 1.50e-4）。这正是这轮想守住的边界——图画的是 C/N，说的是 Eb/N0，两个口径在读数里各自标清。

## 三、第 10 章：两条零阶保持阶梯

上一轮把主图换成量化误差 e(t)，纵轴钉死 ±0.05。用户否掉了：误差图看不见「重建」，而且 ±0.05 在 3 位档根本装不下。这一轮恢复两条阶梯：

- `原信号 s(t)`：抽样时刻的真实值，零阶保持连起来；
- `抽样重建（n bit，零阶保持）`：量化后再零阶保持。

`stairPoints(values)` 把每个抽样值展开成 `[t, v] → [next, v]` 两个折点，所以画出来是台阶而不是折线。`shown = Math.min(8, sampleCount)`，横轴只画前 8 个抽样间隔（`xRange: [0, spanEnd]`），这样 3 位档的台阶高 0.25 在画布上约 55 px 一眼可见，8 位档 0.0078 约 1.7 px 看不见——那是物理事实，用结论里的 SQNR 说，不再靠换图回避。

位数范围从 8…12 改成 3…12（默认仍 8）。三条读数（混叠误差 142.1% / 量化信噪比 / PCM 码率）一个字符没动，`fs=1` 档的 142.1% 仍原样报出。

## 四、第 12 章：两个周期，两根顶到 1

原来 x 轴钉死 `[0,127]` 且只画一个周期，N 变小的时候右边空一大片，而「τ=N 又回到 1」这个周期性事实看不见。改成 `shown = 2 * period`，点序列 `Array.from({length: shown}, (_, i) => [i, auto[i % period]])`：

- `xRange: [0, shown - 1]`（现算，不再写死 127）；
- `yRange: [-1.5 / period, 1.05]`，`yTicks: [0, theorySide, 1]`——三根刻度把「0 / −1/N / 1」三个位置直接标出来；
- `guideLabelAlign: 'right'`：`−1/N` 那条注解原来压在左上，和第一根柱重叠，挪到右上。

`CourseChart` 为此加了两件事：`guideLabelAlign` 可选 prop（`'left' | 'right'`），以及 `bars` 分支在每根柱顶画一个半径 2.1 的实心圆点——光看竖线数不清哪两根顶到 1，有了点就能数。

## 五、第 9 章改名

那条折线画的是 `matchCorr` 加噪声之后的输出，不是噪声本身，名字从「接收噪声实现」改成「含噪匹配滤波输出（σ = …）」。

## 六、第 3 章：空序列不进图例

第 3 章某些档位下集合为空，画布上没线，图例却挂着一个名字，读者会以为图画漏了。新增 `legendItems(series)`：

```ts
return series.filter((item) => !item.quiet && (item.points === undefined || item.points.length > 0));
```

`legendRows`（算折行宽度）与 `CourseLegend`（渲染）都改用它——两处必须是同一个判据，否则折行宽度按 4 条算、实际只画 3 条，右边会缺一块。

## 七、第 13 / 6 / 7 章：参数默认值

`compute({})`（页面在参数还没初始化时就会调一次）以前在几章会出问题：第 13 章三个参数没有默认值 → `NaN` → 判据判成发散红；第 6 章 `alpha`/`eyeSnrDb` 缺省 → seed 里出现 `NaN`；第 7 章 `params.scheme ?? 0` 把「没传」算成 2ASK，而章表默认是 2PSK。

三处补 `??` 默认值：第 13 章 `k ?? 0.6`、`theta0 ?? 2`、`sigma ?? 0`；第 6 章 `alpha ?? 0.35`、`eyeSnrDb ?? 20`；第 7 章 `scheme ?? 2`。这只是参数层兜底，算法一行没动。

顺手加了第 5 章的裁窗（`series` 上超出画布的点裁掉），这是唯一一处主动碰的其它章节。

## 九、这轮的取舍与教训

- **文档这轮只动数字**：测试数 357→359 共 10 处（README 3、preview 1、tech-report 5、works-intro 1），加上轮次表插入 R97 行（表体 96→97 行，必须与 tag 数相等）。正文叙述（第 8/10/12 章的图说）留到 tag 之后再改，避免和图一起改出错。
- `compute({})` 这条新断言直接把第 6、7 章的缺省参数问题逼了出来——原来是「页面第一次渲染和图不一样，第二次才对」的隐藏 bug。断言比人眼可靠。
- 截图脚本里改 `range` 与 `select` 必须用原型上的原生 setter 再派发 `input`/`change`，React 受控组件才认；直接改 `.value` 会被打回去。
- 图例的 DOM 是 `.course-legend .legend-item`（`span` 结构），不是 `li`——第一次取证按 `li` 数，数是 0。
- 探针脚本 `import` 只能用相对路径，`D:/…` 这种绝对路径会被 ESM loader 拒（`ERR_UNSUPPORTED_ESM_URL_SCHEME`，`protocol 'd:'`）。
- CDP 度量前一定要先 `Emulation.setDeviceMetricsOverride`，否则视口只有 ~485 px，两列布局会退化成单列，看着像布局坏了。
