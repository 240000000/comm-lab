## 这一轮要的

第 2 章「能量信号 / 功率信号」两档在图上看起来一样：换档只把纵轴除以窗长 T，曲线形状一个字没变。要让它俩真的不一样：功率档换成真正的周期脉冲串，自相关跟着按周期重复，读数按档分开报，结论句重写物理差别。只动 `computeSignal` 与第 2 章文案。

## 为什么原来两档一样（根因）

`computeSignal` 里只有一行分档：

```ts
const samples = pulseSamples(tau, shape)
```

两档共用同一份单脉冲采样，只在后面按 `expectedDivisor = kind === 0 ? 1 : T` 改纵轴。也就是说「功率信号」从来没有真的产生过周期信号——它只是把同一根单脉冲的自相关缩小 8 倍。按定义，功率信号是功率有限、能量无限、在窗内按周期重复的信号；只除一个常数不会让曲线多出第二个峰，所以两档看着一样不是画错，是信号本身没换。

第二层原因在画图这一侧：`src/labs/CourseChart.tsx:97-109` 的纵轴上下界是从数据点现算的（`yMin = Math.min(yMin, yv)`、`yMax = Math.max(yMax, yv)`），只加 `(yMax − yMin) * 0.08` 的留白（`:145-147`），`dataMin >= 0` 时再把底边夹到 0（`:149`）。轴没有写死量程，完全跟着数据走——整体缩小 8 倍这件事在画面上被归一化吃掉，两档的曲线不但形状像，连落点都一模一样。两层加起来才是「逐点重合」。

第三层原因：即便当时想换成周期串，窗长 T = 8 是固定的，周期必须整除 8，否则循环自相关绕回来时脉冲会跨边界拼接，图上会出现来路不明的半截峰。这条硬约束此前没有写在代码里。

## 一、改成真的周期脉冲串

新增 `periodicSamples(tauMs, shape, periodMs)`：对每个采样点取 `local = (i * dt) % periodMs`，其余与 `pulseSamples` 完全一致（矩形 / 三角两种形状共用一个形状函数）。

选周期的规则写在 `computeSignal` 里：

```ts
const periodCandidates = [1, 2, 4, 8]                 // 都能整除窗长 T = 8
const period = kind === 1 ? (periodCandidates.find((p) => p >= 2 * tau) ?? 8) : 0
const singlePulse = pulseSamples(tau, shape)
const samples = kind === 1 ? periodicSamples(tau, shape, period) : singlePulse
```

挑「能整除 8 且 ≥ 2τ 的最小值」：τ = 1.5 时 2τ = 3，取 Tp = 4；窗里正好两个脉冲。τ = 0.5 时取 Tp = 1，窗里八个脉冲。

## 二、自相关跟着变

循环自相关自动带来了重复峰：峰在 0、±Tp 处，峰高 = 平均功率 P = E/Tp。实测（τ = 1.5、矩形）：

| 横轴位置 | −4 | −3.5 | −2 | −1 | 0 | 1 | 3.5 | 3.97 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 能量档 | 0 | 0 | 0 | 0.5000 | **1.5000** | 0.5000 | 0 | 0 |
| 功率档 | **0.3750** | 0.2500 | 0 | 0.1250 | **0.3750** | 0.1250 | 0.2500 | 0.3672 |

能量档只有一个峰、脉冲外归零；功率档按 4 ms 重复、τ 再大也不衰到零。

## 三、读数按档分开

- `kind = 0`：`自相关峰值 R(0) = 1.5000`（hint「理论 E = …」）——**一个字没变**。
- `kind = 1`：`平均功率 P = 0.3750`（hint 写清 P = E/Tp、单脉冲能量 E、当前 Tp），外加 `相邻峰间隔 = 4.00 ms`（从曲线上量第一个峰的位置，不是直接回读参数）。
- `kind = 2`：仍是 `图上 曲线峰值/T` 与 `原始 曲线峰值`，语义未动。

## 四、反例档与对偶

`kind = 2`（拿 |X| 当功率谱）的对偶偏差仍是 `9.47e-1`、`failed = true`，判据 `deviation > 1e-3` 没动。

对偶两条线在三个档下都逐点相等（偏差 0，机器精度）：周期串是 DFT 能精确表示的，只要 Tp 整除窗长，实测自相关与功率谱反变换的关系不受影响。这一条是本章立论，不通过就回去改 Tp，不放宽判据。

## 五、结论句

`kind = 1` 重写为：能量信号的自相关只在脉冲宽度内非零、τ 再大就归零，峰的读数直接是能量 E；功率信号换成了周期 Tp = 4.00 ms 的脉冲串，自相关跟着按周期重复、τ 再大也不会衰到零——它读的是平均功率 P = E/Tp = 0.3750，不是能量；两条线照样贴在一起，偏差 0。

第 2 章的 `question` 也从「脉冲的自相关，为什么能和它的功率谱对上？」改成「同一个自相关，为什么能量信号只开一个峰、周期功率信号开一串？」。
