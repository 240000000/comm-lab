# R96 · 扩展面板：入口卡变书架、功能模块表两列

用户这一轮的边界很清楚：只动扩展面板。课程视图内部不改，首页四张卡一个字不动，第 10 章只许改一行 series 名。理由也给了——扩展面板现在有两个进课程视图的口子（书架上的书、另一张「05 课程视图 · 13 章」的入口卡），而入口卡不认书；功能模块表按书里的章排四列，换个说法就是「这本书的目录」，17 个功能里这本书没有的章根本不在表里。

## 一、这一轮要做的

1. 删掉入口卡，进课程视图唯一入口改成点书架上的书。
2. 功能模块表从四列改两列「功能 / 状态」，行轴固定 13 个功能名。
3. 第 10 章 series 名改成「抽样时刻量化误差（N bit）」。
4. 顺手把 README 里描述扩展模式的那几句改成事实。

## 二、入口卡：删掉，不是藏起来

`src/App.tsx` 里那张卡是 `<a className="course-entry" href="#/course">`，含 `card-index` 的 05、「课程视图 · 13 章」、一段说明和「进入 →」。它跟书架并列，等于告诉用户「进课程视图不用选书」。删掉之后 `home-extra` 只剩 `<ShelfPanel>` 和 `<ModulePanel>`。

卡片右边那句「只读你的目录，不读正文；PDF 不上传，原文件只存在这台机器的浏览器里。」是书架的承诺，不是入口卡的。删卡时把它整段挪到书架面板底部（`.shelf-promise`），一个字没改。

CSS 一并清：`.course-entry` 两处、`.home-extra-note` 两处、`@media` 里两处列名。留着等于给不存在的元素写样式。

## 三、书架行变成唯一入口

`src/labs/ShelfPanel.tsx` 的每一行本来是个 `<button className="shelf-pick">`，点它只是把这本设为当前书，页面不跳。这一轮改成：

- 行内加一个淡色的「进入 →」（`.shelf-enter`），右侧留白处，`grid-area: enter` 跨三行垂直居中。
- `aria-label` 写「进入《书名》的课程视图」——读屏软件听到的不是三个 span 的拼接。
- `App.tsx` 里新增 `enterCourse`：先 `setActive(id)`，再 `window.location.hash = '#/course'`。

路由不用动。`App.tsx` 本来就订阅了 `hashchange`（`useState(currentRoute)` + `addEventListener('hashchange', onHashChange)`），程序化改 hash 会触发重渲染；`src/router.ts` 的 `parseHash` 只认问号前的路径，`#/course?no=N` 这种深链照旧。

## 四、功能模块表：四列变两列，行轴换成 13 个功能

原来的表是「章 / 书上原字标题 / 命中词 / 状态」，行来自 `book.chapters`。问题在于它回答的是「这本书的每一章能不能点」，而不是「课纲上的每个功能这本书讲没讲」——后者才是用户点开这张表时想问的。

现在行轴固定 13 个功能名（信息量与熵、确知信号的能量谱与功率谱、各态历经与统计平均、信道容量与香农公式、模拟调制的噪声性能、眼图与码间串扰、2ASK·2FSK·2PSK 的误码率、QAM 与 OFDM 的谱效率、最佳接收与匹配滤波、抽样、量化与 PCM、汉明码的纠错能力、m 序列与正交编码、锁相环的锁定），状态列只写两种话：

- 命中：`本书第 N 章「书上原字标题」`
- 没命中：`本书未涉及`

命中词不进正文，塞进单元格的 `title`，鼠标悬停才出来——它是给核对着的证据，不是给读者看的正文。13 行都可点，跳 `#/course?no=<N>`；未涉及的行淡色但仍可点，`title` 写「本书未识别到这一章，仍可进入默认示例」。表底两行数字是现算的：`13 个功能：本书覆盖 N 个、未涉及 M 个。`，若这本书还有没识别出来的章，再加一句「本书另有 K 章未识别。」（沿用原来的措辞）。

## 五、coverageOf：把「覆盖」变成一个纯函数

`src/course/shelf.ts` 新增 `MODULE_FUNCTIONS`（13 条）、`coverageOf(book)`：

```ts
export function coverageOf(book: ShelfBook): Coverage {
  const rows = MODULE_FUNCTIONS.map((item) => {
    const chapter = book.chapters.find(
      (entry) => entry.topicId === String(item.no) && isPlayable(entry),
    ) ?? null
    return { no: item.no, name: item.name, chapter, title: chapter ? evidenceOf(chapter) : MISSING_FUNCTION_HINT }
  })
  return {
    covered: rows.filter((row) => row.chapter !== null).length,
    missing: rows.filter((row) => row.chapter === null).length,
    unknown: book.chapters.filter((entry) => !isPlayable(entry)).length,
    rows,
  }
}
```

两个条件缺一不可：`topicId` 对上，而且那一章真的可玩（`isPlayable`）。只对上 `topicId` 但模型没实现，写成「本书第 N 章」就是虚报。

## 六、第 10 章那一行

series 名从「量化误差 e(t)（8 bit）」改成 `` `抽样时刻量化误差（${bits} bit${companding === 1 ? '，A 律' : ''}）` ``。加「抽样时刻」四个字是因为 R95 把这张图的口径定成了只取采样时刻的误差（零阶保持的中段误差是保持误差，不是量化误差，塞进 ±0.05 会整条出框）。y 轴标题没动。`src/core/course.ts` 本轮只改这一行。

## 七、README 三处

- 「功能模块表列出这本书的每一章能不能交互」→「功能模块表按 13 个功能逐条说这本书覆盖没覆盖。」
- 「扩展模式是两块并排：左边是书架，右边是功能模块。」→ 右边写成「13 个功能的覆盖表」，并补一句「进课程视图点书架上的书。」
- 四列表那整段换成两列表：第一列固定 13 个功能、第二列两种话、命中词在 `title` 里、13 行可点 `#/course?no=N`、未涉及行淡但可点、表底现算覆盖数与未识别章数。
- 「下面还有一张课程视图的入口卡（`#/course`）。」→「点书架上的某本书就进这门课的课程视图（`#/course`）。」
