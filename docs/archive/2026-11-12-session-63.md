## 一、这一轮要做的三件

1. `src/course/pdfOutline.ts` 原来只吐章级书签（`walkOutline` 里只认 `isChapterTitle` 为真的条目，节、小节全丢），改成三级全收，每条带 `depth`（0 章 / 1 节 / 2 小节）与所属章号；`bookFromOutline` 签名不动，另加 `bookFromSections(title, entries, id)` 走新路径。
2. 聚合规则写成纯函数：每章把章下所有节/小节的标题过一遍 `matchChapter`，按主题投票，命中 ≥ `SECTION_MIN_HITS`（写死 2）的主题认这一章；不够 2 票退回章名匹配；章名也不行判未覆盖。
3. `evidenceOf` 对节级认出的章，要把触发它的节名原文印出来（如「2.1 确知信号的类型」），功能模块表第三列直接显示。

红线：通信原理默认书 13 章映射一字不变、13 章 compute 一行不动、首页四卡与 hero 不动、不写 localStorage、不引新依赖。

## 二、第一步：三个层级的书签，与一个必须记下来的坑

`pdfOutline.ts` 的改动：

- `OutlineEntry` 加可选 `depth?: 0 | 1 | 2` 与 `chapterNo?: number | null`（老的调用方不写这两个字段，按章处理）。
- `walkOutline` 改成深度递归：章标题（`chapterNumberOf` 非空）记 `depth: 0` 并把章号往下传；非章条目按父层深度记 1 或 2。
- `chapterEntriesFromOutline` 与 `toBook` 内部都只取 `depth ?? 0 === 0`，所以旧签名、旧调用方（`toBook(entries)`）行为不变。
- 新增 `sectionEntriesFromOutline(nodes)`，三级全收。

**第一版按缩进判断归属，真书直接打脸**：296 条书签的 `byDepth` 是 `{0: 13, 1: 0, 2: 283}`、`chapterNo` 全是 `null`。原因是这本 PDF 的书签是**平的**——`封面 / 书名 / 版权 / 前言 / 目录`，与 `1.1 通信的基本概念`、`1.1.1 通信的发展` 和 `第1章 绪论` 全排在同一层。缩进在这本书里不代表从属关系。

修法是改看标题里的编号（这是最硬的证据）：

- 新增 `sectionNumberOf(rawTitle)`，正则 `^(\d{1,2})\s*[.．]\s*(\d{1,2})(?:\s*[.．]\s*(\d{1,2}))?`：`5.1 …` → `{chapterNo: 5, depth: 1}`，`5.4.3 …` → `{chapterNo: 5, depth: 2}`。
- 新增 `normalizeHits(hits)` 按文档顺序修一遍归属：章标题 → 自己的章号；有编号 → 用编号里的章号与层级；没编号的（「本章小结」「习题」）→ 跟着前面最近的一章走；开头封面/目录那种落在章外，留 `null`。
- `sectionEntriesFromOutline` 与 `readOutline` 都先过 `normalizeHits`。

修完真书 `byDepth` 变成 `{0: 13, 1: 95, 2: 188}`，95 个节、188 个小节各有归属。

## 三、第二步：聚合规则（纯函数，在 `src/course/sections.ts`）

- `SECTION_MIN_HITS = 2`，写死。注释里写明理由：写死不是因为它精确，是因为一旦可配，就会有人凭手感把它调成 1，然后「一条节名认一整章」。
- `groupSections(entries)`：按 `chapterNo` 把节收进各自的章；章外条目不塞给任何人。
- `matchBySections(sections)`：每个节名过 `matchChapter` 投一票，票数 `< 2` 的主题直接丢弃；取票数最多，平手取主题号小的（确定性，不按手感）；返回 `{ topicId, hits, count }` 或 `null`。
- `assignTopics(chapters)`：先把有节级候选的章按「票数降序、章号升序」排队认领，同主题只给一章（`taken` 集合），认中记 `by: 'section'`；剩下的章再走一遍章名匹配，主题已被节级认走就跳过，认中记 `by: 'chapter'`；都没有就是 `by: 'none'`。

两条边界在单测里钉死：某章只有 1 条节名命中时不许认章；两章抢同一主题，票数多者得，平票章号小者得。

## 四、第三步：证据要能看见

`ShelfChapter` 加 `sectionHits?: string[]`；`bookFromSections(title, entries, id)` 把 `assignTopics` 的结果映射成书架章，保留 `sectionHits`。

`evidenceOf` 改成分支：有 `sectionHits` 时输出 `→ 确知信号，节名命中「2.1  确知信号的类型」「2.2  确知信号的频域性质」`；没有时退回原来的 `，命中「关键词」`；不可玩仍是「未识别到对应模型」。

功能模块表第三列本来就渲染 `evidenceOf`，所以不用改 `ModulePanel`，节名证据自然出现。
