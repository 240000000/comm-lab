export type Book = { id: string; title: string; chapters: BookChapter[] }

`BOOK_COMMUNICATION` 的 `id` 是 `'communication-principles'`，`title` 是 `'通信原理'`，13 条按教材顺序：绪论 / 确知信号 / 随机过程 / 信道 / 模拟调制系统 / 数字基带传输系统 / 数字带通传输系统 / 新型数字带通调制技术 / 数字信号的最佳接收 / 信源编码 / 差错控制编码 / 正交编码与伪随机序列 / 同步原理。

## 二、`src/course/match.ts`：约 90 条关键词的三本书映射

```ts
export type MatchResult = { topicId: string; score: number }
export function matchChapter(rawTitle: string): MatchResult | null
```

关键词表按章分组，每章 4–10 个同义写法。除教材原名外，收的是「真能映射到现有仿真」的外来章名：

- 第 1 章 绪论：引论、绪言、概述
- 第 2 章 确知信号：确定性信号、信号分析
- 第 3 章 随机过程：随机信号、平稳随机、窄带随机、白噪声
- 第 4 章 信道：信道模型、信道容量、恒参信道、随参信道、通道
- 第 5 章 模拟调制系统：模拟调制、角度调制、幅度调制、双边带、单边带、残留边带、调幅、调频
- 第 6 章 数字基带传输系统：数字基带传输、基带传输、线路码型、码间串扰、升余弦、眼图、基带
- 第 7 章 数字带通传输系统：数字带通传输、带通传输、频带传输、2ask/2psk/2fsk/2dpsk、键控
- 第 8 章 新型数字带通调制技术：正交幅度调制、正交频分复用、最小频移键控、QAM、OFDM、MSK
- 第 9 章 数字信号的最佳接收：最佳接收机、最佳接收、匹配滤波器、匹配滤波、最大似然
- 第 10 章 信源编码：脉冲编码调制、抽样定理、增量调制、量化、PCM、A 律
- 第 11 章 差错控制编码：差错控制、纠错编码、信道编码、线性分组码、汉明码、卷积码、循环码、检错
- 第 12 章 正交编码与伪随机序列：伪随机序列、正交编码、m 序列、伪随机、沃尔什、巴克码、扩频
- 第 13 章 同步原理：载波同步、位同步、群同步、帧同步、网同步、同步

**故意不收**「概论 / 导论 / 原理 / 分析 / 系统 / 网络 / 线性 / 初步 / 实验」这类泛词——收了它们，`操作系统概论`「财务报表分析」就会误命中，而这一轮的验收明确要求无关章名返回 null。

三层处理：

1. `normalize()`：`trim().toLowerCase()` → 去掉 `第X章/节/部分` 前缀 → 去掉所有非字母数字字符（`replace(/[^\p{L}\p{N}]+/gu, '')`）。首版用的字符类写法有正则歧义，改成 Unicode 属性类。
2. 打分：`EXACT_BONUS = 1000`，整串命中得 `1000 + 词长`，包含命中得 `词长`；长度 < 2 的词记 0 分。
3. 选优：分高者胜 → 同分取更长的词 → 再同分保留表内先出现的（表序即优先级，越靠前越具体）。空串或纯空白直接返回 null。
