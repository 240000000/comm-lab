## 三档阈值与理由

`src/core/course.ts:297` 之后：

```ts
// 图上那条线的噪声 σ 相对消息峰值 1.0 有多大，决定结论句怎么说。
// 0.15 以下肉眼几乎看不出毛刺；0.5 以上消息的包络已经被噪声埋掉，说「贴着消息」就是撒谎。
const NOISE_QUIET = 0.15
const NOISE_BURIED = 0.5
```

- 取 σ 而不是 outSnr 分档：σ 就是图上那条线的噪声幅度比，和读者看到的东西一一对应；outSnr 还要在脑子里做 `10^(−x/20)` 换算。
- 0.15：σ=0.15 时噪声幅度只有消息峰值的 15%，一条 1 kHz 正弦上叠 15% 的毛刺仍能一眼看出形状，这是「干净」的上界。
- 0.5：σ=0.5 时噪声已经吃掉了消息的一半幅度，正弦的轮廓开始碎；再往上（σ≥1）整个波形被噪声主导。取 0.5 作为「还看得出形状」与「已经被盖住」的分界，比取 1.0 保守一档，避免图上已经糊了还在说「能看出形状」。

## 两处文案改法

### 1. 结论句（正常分支首句）

原来由 `` `解调输出贴着消息，失真 ${fixed(distortion*100,1)}%，带宽实测 …` `` 开头，现在整句交给 `noiseSentence(mixSigma, outSnr, distortion)`：

```ts
function noiseSentence(sigma: number, outSnr: number, distortion: number): string {
  const readings = `读数（失真 ${fixed(distortion * 100, 1)}%、带宽、输出信噪比 ${fixed(outSnr, 1)} dB）都按理想路径算，不是从图上量的`
  if (sigma < NOISE_QUIET) return `解调输出贴着消息，${readings}。`
  if (sigma < NOISE_BURIED) return `解调输出开始起毛，还能看出消息形状；${readings}。`
  return `这条线已经被噪声盖住，图上看不出消息；但${readings}。`
}
```

三档都把「读数按理想路径、不是从图上量的」写在同一条句子里，读者不会以为 0.0% 是从那张糊掉的图上量出来的。

### 2. `输出信噪比` 的 hint

尾部追加 `` ` · ${noiseHint(mixSigma)}` ``：

```ts
function noiseTierPhrase(sigma: number): string {
  if (sigma < NOISE_QUIET) return '图上基本干净'
  if (sigma < NOISE_BURIED) return '图上开始起毛'
  return '图上已被噪声盖住'
}
```

hint 里同时给出 `σ = X` 与档位短语，读数区和图说的是同一件事。
