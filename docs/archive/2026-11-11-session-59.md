## 一、这一轮要做的

用户指出的是文案病，不是算法病：第 1 章「拿单次信息量当平均」这个反例，读数与 `failed` 都对，但结论句写的是

```

```

`info / entropy` 是**比值**，被写成了「差」。三个位置三种读法：

- p=0.01：6.64 / 0.081 = 82.2 倍，说「差 82 倍」勉强能懂；
- p=0.99：0.0145 / 0.081 = 0.18 倍，中文里「差 0.18 倍」直接读不通，意思是「差五分之一倍」？没人知道；

同一句话在读数卡片的 hint 里也有一份（`两者差 ${…} 倍`），一处也没少。

## 二、上一轮的断言为什么是绿的

`tests/course.test.ts` 里那条错档断言的病灶只有一行：

```ts
const ratio = Math.max(measured / entropy, entropy / measured)
assert.ok(ratio >= 5, `错档的偏差只有 ${ratio.toFixed(2)} 倍，不够「差几倍」`)
```

`max()` 把方向抹平了。p=0.99 时实测比熵小 5.57 倍、p=0.01 时大 82 倍，两种情形都满足 `>= 5`；文案里把「大 82 倍」写成「小 82 倍」，这条断言照样绿。**方向错的时候它是绿的**，这是这一轮真正的教训。

## 改法：一个纯函数，三档

`src/core/course.ts` 新增导出 `infoGapText(info, entropy)`：

```ts
export function infoGapText(info: number, entropy: number): string {
  if (Math.abs(info - entropy) < 1e-9) {
    return `两种口径在 p = 0.5 恰好给出同一个数（${info.toFixed(3)} bit），错在这一档看不出来——把 p 拖到 0.01 或 0.99，差别才会露出来`
  }
  if (info > entropy) {
    return `单次信息量是平均的 ${(info / entropy).toFixed(2)} 倍`
  }
  return `单次信息量只有平均的 ${((info / entropy) * 100).toFixed(1)}%，反过来平均是单次的 ${(entropy / info).toFixed(2)} 倍`
}
```
