  1. **版本锚点句式**恰好一处，且 `本文件对应仓库 tag \`Rx\`` 里的 tag 在 `git tag -l` 里真实存在；

## 卡在哪

- 这类「文档里写自己有多少 tag」的错，R48 在技术报告上修过一次、这轮在作品介绍上又修一次——同一个毛病的第二个落点。教训是不该靠「记得改」，应当靠句式禁令：`SELF_REF` 五条正则 + 本轮三条扫描，现在两份文档都扫。
- 版本锚点用「对应某个 tag」而不是「最新 tag」，是因为这份文件是一次性交出去的快照；锚在固定 tag 上，仓库往前走它不动，也不会误导评委以为它描述的是最新状态。
- `post.py` 仍然非幂等，但本轮作品介绍走的是 md2docx + topdf 的两步链，没有 post.py 这一步。
