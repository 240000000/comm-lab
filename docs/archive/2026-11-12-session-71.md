## 三、参数标签与结论补滚降代价

结论在原有四分支之后追加一句，把「左移 ≠ 更好」写死：

```
别把左移读成「滚降越大越好」：同样带宽里能塞的比特率是 log2(M)/(1+α) = 2.96 bit/s/Hz，α 越大这个数越小。滚降是拿带宽换旁瓣，不是白捡的 dB。
```

这句直接由 `log2(M)/(1+α)` 现算，不写死数字。理由是页面上的「让它失效」按钮：它把 α 拖到 0.9 让曲线左移、看起来更漂亮，如果没有这句，用户得到的是一个反着的结论。

## 九、这一轮的取舍与教训

- **读数与横轴必须同框交代**。图换了坐标系而读数没跟上，读者拿两个数对不上，会怀疑图算错了。折算串放在读数说明里比放在正文更好——读数本来就在用户拖参数时实时变。
- **结论要写代价，否则按钮起反作用**。「让它失效」演示的是 α 变大曲线左移，单看曲线是「变好了」；补 `log2(M)/(1+α)` 才让这个演示回到「带宽换旁瓣」。
- **压页先量再调**。抽第 30、31 页看到「整页只有第四章」，才知道不是正文变长而是分页标记的位置问题；第一档杠杆一动就少两页，没进第二档。
- **封面提交号是重导触发器**。凡 amend 或重打 tag，PDF 必须整链重跑一遍，不能只重跑 `topdf.ps1`。
- 本轮 amend 1 次（把轮次表压描述的改动并入同一提交，并在未推送前重指 tag R98）；推送顺序是先 tag 再 main。
