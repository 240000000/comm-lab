## 二、为什么只放宽 .course，不放宽 .lab

`.lab` 这一条（`src/App.css:239`，`width: min(1080px, 100% - 48px)`）被**四个实验台共用**：QAM 星座台、卷积码台、OFDM 台、任务模式台。把 1080 改成 1360，等于让四个已经验收过的实验台整体重新排版一次——画布宽高、卡间距、读数折行全要重看一遍，而这一轮只买了「课程视图一屏更大」这一件事。课程页的 `main` 是 `className="lab course"`，`.course` 叠在后面、权重相同、靠源码顺序覆盖，所以只加一条 `.course` 就够，实验台一点不受影响。

**首次实测没生效**：`.course` 块一开始写在 `.lab` 之前，两条同为单类选择器、同权重，源码在后的 `.lab` 胜出，1920 下 `main` 仍是 1080。把 `.course` 整块移到 `.lab` 块之后，同一次测量就变成 1360。这个坑写进注释了：「靠源码顺序覆盖，所以这条必须排在 .lab 之后」。

## 三、画布高度：chartHeightFor 与六处替换

新增 `src/labs/chartHeight.ts`（纯函数、不碰 DOM）：

```ts
export const CHART_HEIGHT_MIN = 320
export const CHART_HEIGHT_MAX = 520
export const CHART_HEIGHT_RATIO = 0.42
export function chartHeightFor(width: number): number {
  const raw = Math.round((Number.isFinite(width) ? width : 0) * CHART_HEIGHT_RATIO)
  return Math.min(CHART_HEIGHT_MAX, Math.max(CHART_HEIGHT_MIN, raw))
}
```

`CourseChart.tsx` 原先的 `const HEIGHT = 320` 被删，六处引用全部改成 `draw` 里按 `widthRef.current` 现算的局部 `const height`：建位图（`syncCanvasSize(canvas, width, height, dpr)`）、清屏、算 `plotH`、画横轴标题（`height - 8`）、内联 style（改走 `cssHeight` state）、以及内联样式的高度值。宽度一变，`ResizeObserver` 更新 `widthRef` 后重画，`height` 是每次现算的，自然跟上。堆叠柱分支里原来也有个 `const height`（柱高），改名 `barH`，免得遮蔽外层。

`grep -n "HEIGHT" src/labs/CourseChart.tsx` 现在 0 命中。

## 五、首页 untouched：怎么证的

直接整页比对**过不了**，两次都不一样：未冻结时 base 516290 B / cur 515936 B，逐像素差 8859 px，bbox `(1126,20)-(1577,483)`；冻结 rAF 之后差 23008 px，bbox `(62,700)-(1857,1099)`。差异区都在 `canvas.home-particles`（hero 那个 1920×1100 全屏逐帧动画画布）里——相位取自实时帧，等多久都不定。三种冻结法（rAF 只跑 24 帧、时间戳固定、时间戳恒定）都试过：前两种能拍出「同一张」，但 base 与 cur 仍不同；第三种四张四个字节数，反而更乱。

改判据之后两次都过：

1. **DOM 几何**：两版各取 body 下所有可见元素（`top ≤ 900`）的 tag/class/left/top/width/height/文本前缀，36 条 tuple 逐字相同。四张 `.card` 均 531×184（y 438/438/640/640），`main.shell` 1080×940，`footer.foot` 1080×40，`scrollH 1100`。
2. **遮掉画布再逐字节比**：注入 `canvas{visibility:hidden !important}` 后拍三张（base / cur / cur 再拍一次），三张**字节完全相同**：171307 B，sha256 `869accf6ea1c5ca5f08df3e2662a1721`，逐像素差 **0**。

所以「首页 identical」的口径是：除 hero 动画画布本身（逐帧相位）之外，首页逐字节相同。
