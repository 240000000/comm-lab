## 第二部分：首页左下角的三维曲线

### 纯函数 `src/labs/curvePoints.ts`

- `export const CURVE_SAMPLES = 220`、`export const CURVE_PERIOD_MS = 9000`。
- `homeCurvePoint(u, phase)`：`turn = u * TAU + phase`；半径 `1 + 0.42 * cos(3 * TAU * u)`（三瓣，所以同一圈里会离轴远近变化），高度 `0.55 * sin(2 * TAU * u)`（上下两次），输出 `{ x: r * cos(turn), y: h, z: r * sin(turn) }`。
- `homeCurvePoints(phase, samples = CURVE_SAMPLES)`：`u` 从 0 走到 1，返回 `samples + 1` 个点（首尾重合，供描边闭合）。
- `phaseAt(elapsedMs, periodMs = CURVE_PERIOD_MS)`：`(elapsedMs / periodMs) * TAU`——时间到相位的唯一入口，组件不再自己算角度。

### 组件 `src/labs/HomeCurve.tsx`

- 文件内常量：`NARROW_PX = 1280`、`TILT = 0.42`、`FOCUS = 4.2`、`TEAL = '60, 227, 198'`。
- `project(point, width, height)` 里 `unit = Math.min(width / 3.05, height / 2.45)`，投影中心 `width * 0.46` / `height * 0.42`，透视系数 `FOCUS / (FOCUS - z * …)`。第一版是 `unit = min(w/3.6, h/2.6)`、中心 `0.5 / 0.56`，闭合环会被页面底边切掉一截，重截后改成上面的值。
- 描边按深度分段：每段透明度 `0.14 + 0.3 * near`、线宽 `0.9 + 0.7 * near`，所以远端细淡、近端稍实。
- 位图尺寸走 `syncCanvasSize(canvas, width, height, dpr)`，返回 `true` 时才 `ctx.setTransform(dpr, 0, 0, dpr, 0, 0)`；`ResizeObserver` 观察 canvas 自身。
- `matchMedia('(prefers-reduced-motion: reduce)')` 命中时只 `draw(0)` 画一帧、不申请 rAF；正常时 rAF 循环，且只有 `window.innerWidth >= NARROW_PX` 才画。
- 组件不读任何全局状态，只用 `performance.now()` 差值和自己的 canvas 尺寸。
