## 四、第三件：给画布补一句话

`CourseChart.tsx` 的 `<canvas>` 对读屏器是空白。这一轮加 `role="img"` 与动态 `aria-label`，拼装抽成纯函数放 `src/labs/chartLabel.ts`：

```ts
export type ChartLabelInput = {
  no: number
  title: string
  question: string
  readouts: ReadonlyArray<{ label: string; value: string }>
}

export function chartLabel(input: ChartLabelInput): string
```

输出格式：`第 N 章 · 章名：问句；读数 名字 值、名字 值、名字 值`。问句句尾的 `。．.！!？?` 一律裁掉再接分号（不然会出现「…闭上了？；读数」）；没有读数时不留孤零零的分号。**不拼结论句**——读屏器读到一整段结论会淹没读数，只报数等于没报名字，所以名字和值都留。

`CourseChart` 的 props 加了必填 `label: string`，由 `CoursePage` 传 `chartLabel(...)` 进来；三条单测在 `tests/chartLabel.test.ts`：章号+章名开头、含问句、含三个读数的值与名字、一位数章号且问句带句号时的整串精确匹配。

第 6 章实测 `aria-label` 原文：

```

```
