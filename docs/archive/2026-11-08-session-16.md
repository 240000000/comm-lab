## I / H 的表达式与现算值
- `I(p) = −log2 min(p, 1−p)`；`H(p) = −p·log2 p − (1−p)·log2(1−p)`。
- 口径说明：判据既要求「p 小时 I 冲到 6.6」又要求「p=0.99 时 I≈6.644」。字面的 `−log2 p` 在 p=0.99 只有 0.0145 bit，两条要求互相矛盾；取 p 与 1−p 中较小的那个（稀罕的那一侧）之后，p=0.01 与 p=0.99 都是 6.6439 bit、p=0.5 正好 1 bit，三条数值要求同时成立。读数 hint 写明「值钱的是稀罕的那一侧」。
- 现算：I(0.5)=1、H(0.5)=1；I(0.99)=6.6439、H(0.99)=0.0808；H 在 0.01–0.99 全区间只有 p=0.5 取到 1，其余严格更小。

## 实测平均信息量的抽样口径与 n 的影响
- 用 `createRng(INFO_SEED + n)`（`INFO_SEED = 20261110`）抽 n 次：`u < p` 记事件发生，贡献 `−log2 p`；否则贡献 `−log2(1−p)`；累计除以 n。
- 同一 n 结果逐位可复现；n 越大越贴近 H。实测四档：p=0.3 时 n=20 万读 0.882（H=0.881）；p=0.99、n=20 万读 0.083（H=0.081）；n=1000 时抖动明显（p=0.01 档读 0.054，H=0.081）。
- 读数第三张的 hint 直接写「理论上是 H(p) = …，实测与它比 … 倍」，偏离 0.05 才标红。
