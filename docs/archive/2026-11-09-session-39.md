## 一、第 2 章归一化：改前 / 改后

### 改前

`src/core/course.ts:140` 只有一个三元表达式决定除数：

```ts
const expectedDivisor = kind === 1 ? T : 1
```

- 实线 `:164` 是 `autocorr[...] * dt`，**永远不除**；虚线 `:173` 是 `(autocorr[...] / expectedDivisor) * dt`。于是「功率信号」这一档的两条线恒差 8 倍，对偶偏差恒 0.875 并标红——屏幕一边给正确的 `平均功率 R(0)/T = 0.1875`，一边把整档判成失败。
- 反例又是这一档（`:2199` `failPreset: { tau: 1.5, shape: 0, kind: 1 }`），等于把「合法的功率信号」当成了「算错的信号」。
- 两条线本来就来自同一个 `autocorr` 数组，所以除了这个除数，判据永远不可能失败。

### 改后

`computeSignal` 里除数按档位算，两条线共用同一个除数：

```ts
const used = idftReal(kind === 2 ? spectrumMagnitude(samples) : spectrumSquared(samples))
const reference = kind === 2 ? idftReal(spectrumSquared(samples)) : used
const expectedDivisor = kind === 0 ? 1 : T
```

- `spectrumSquared` 不变（`|X|²`），新增 `spectrumMagnitude`（`dft(x).map(c => Math.hypot(c.re, c.im))`）与 `idftReal(spectrum)`：`kind=2` 的实线走 `idft(|X|)`，虚线仍走参考线 `idft(|X|²)`，两条线**都**除 `T`。
- 判据的参照系是**虚线**（参考线）而不是实线：`peakAbs` 取 `fromPsd`。若拿被除过的实线当分母，`kind=2` 的偏差会被放大到 17 倍，失去「0.9 量级」这个可比量。
- `pointsOf(source)` 统一生成两条 series 的点，实线在 `kind=2` 时改名为 `幅度谱 |X| 反变换`。
- 读数：`kind=0` 单行 `自相关峰值 R(0)`；`kind=1/2` 两行 `图上 自相关 R(0)/T`（hint 写明「图上实线用的是这个刻度」）与 `原始自相关峰 R(0)`（hint 写明「能量口径的峰，还没除 T」；`kind=2` 时改成「谱用错了，这个峰已经不等于能量 E = 1.5000」）。
- 结论句三套，数字取同一次 compute：能量档两条线逐点相同；功率档都除 `T` 后仍重合；反例档形状变了、偏差 0.9 量级，根因是功率谱必须是 `|X|²` 而不是 `|X|`。
- `kindParam` 从 `min:0, max:1` 放开到 `max:2`，文案「能量信号 / 功率信号 / 错用幅度谱」；`failPreset` 改指 `kind: 2`。
