## 这轮要解决什么

课程视图一直是「一屏一实验」，学生要对照教材得在浏览器和 PDF 阅读器之间来回切。这轮把原书 PDF 并到实验旁边：宽屏两栏、窄屏抽屉，切章自动翻到这一章的起始页。

上一轮（R104）已经能把 PDF 文本抽出来切节，这一轮只做「看」：书的目录记录里必须有页码，否则切章只能回第 1 页。查下来导入链里页码一直存在，只是 `bookFromSections` 与 `plainChapter` 在写进书架时把它丢了——这是这轮第一个要修的地方。

## 改了什么

- `src/course/pdfSource.ts`（新）：`getBookPdf(id)` 从 IndexedDB `pdfs` store 取 blob（取不到或无 `indexedDB` 时返回 null）；`loadDoc(id)` 把同一个 `bookId` 的解析 Promise 缓存在模块级 Map 里，同一会话只 parse 一次；`closeBook(id)` 调 `destroy()` 并清缓存；`hasTextLayer(doc)` 抽样前五页、累计不足 50 字符判扫描件（本轮只导出）。
- `src/labs/PdfPane.tsx`（新）：`getPage(page)` + `getViewport({ scale })` 渲染到 canvas；位图尺寸走 `syncCanvasSize(canvas, width, height, dpr)`；翻页与缩放前 `cancel()` 上一条 renderTask；加载中显示骨架条，渲染中的旧图用 `is-rendering` 藏起来；控件只有上一页、页码输入、下一页、三档缩放。
- `src/labs/book-pane.css`（新）：宽屏 6:4 三列（目录 264px + 实验 6fr + 书 4fr），书栏 sticky；≤1080px 折成右侧抽屉，抽屉内「收起」按钮可见；≤860px 单列。
- `src/course/shelf.ts`：`ShelfChapter` 加 `page?: number | null`；`bookFromSections` 从章级条目带出页码；新增 `clampPage(page, pageCount)` 与 `chapterPage(book, no)`（topicId 或章号匹配，缺省第 1 页）。
- `src/course/shelfDb.ts`：`plainChapter` 保留 `page`，存取一个来回不丢页码（这是本轮实际修掉的一个 bug，第一次截图时页码全变成 1）。
- `src/labs/CoursePage.tsx`：`showBook` 开关；页选择按 `book.id:no` 派生，切章自动翻页、手动翻页在切章前一直有效；书栏无原件时显示指定提示；窄屏抽屉内可「收起」。
- `tests/courseBook.test.ts`（新，7 条）：章到页映射、`bookFromSections` 带页码、页码夹紧、无原文件返回 null、同一本书只解析一次且 `closeBook` 后重解析、`hasTextLayer` 阈值、存盘读回页码不丢。
- `tests/shelf.test.ts:156`：旧断言「页码不该留在书架里」与 R105 冲突，改为断言页码保留。

## 取舍与教训

- 页码不是「本来就有」：`bookFromSections` 与 `plainChapter` 两处都丢过，第一次截图读到页码恒为 1 才发现。凡是跨「解析 → 存储 → 读回」链路的字段，都要在存储层补一条往返测试。
- 窄屏抽屉必须自带关闭入口：抽屉是 fixed 全高，页顶的「收起书栏」被盖住，没有抽屉内的「收起」就关不掉。
- 渲染与截图之间要等：headless 下 PDF 首帧可能十几秒才画完，截图脚本改为轮询 canvas 像素再拍，避免拍到骨架条。
