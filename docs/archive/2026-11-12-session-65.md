## 二、第一件：曲线从底边走出去，不是贴着底边平推
`src/labs/BerCurveChart.tsx` 原来画理论曲线时写 `const y = toY(Math.max(point.theory, 1e-6))`——下沿以下是画不出来的，夹一下就变成一条贴着底边的直线，读起来像「理论误码率到 1e-6 就不再下降」。这不是画法问题，是把不确定画成了确定。

改成画笔状态：点非有限或 `< 1e-6` 时 `pen = false`、`continue`；下一个有效点先 `moveTo` 再 `lineTo`。路径在底边处断开，曲线自己走出去。

四档实际起断位置（`theoryBer(order, snrDb)`，0–20 dB 以 0.25 dB 扫，1e-6 为下沿）：

| 阶数 | 起断 dB | 起断前一点 | 20 dB 处的理论值 |
|---|---|---|---|
| BPSK | 10.75 | 10.50 dB 1.32e-6 | 1.04e-45 |
| QPSK | 13.75 | 13.50 dB 1.28e-6 | 7.62e-24 |
| 16QAM | 全段不断 | 20 dB 仍 2.90e-6 | 2.90e-6 |
| 64QAM | 全段不断 | 20 dB 仍 8.49e-3 | 8.49e-3 |

16QAM 与 64QAM 在 0–20 dB 内根本到不了 1e-6，所以本轮它们看不见断点——这不是没改，是这两档本来就还没跌到下沿。

## 三、第二件：刻度交给 niceTicks
原来 `for (let db = fromDb; db <= toDb; db += 1) if ((db - fromDb) % 4 !== 0) continue …`：步长写死 1 dB、每 4 dB 一根，量程一变（比如曲线只扫 0–8 dB）就只剩两根甚至一根，横轴等于没有刻度。

新增 `src/labs/berTicks.ts`：`berTicks(fromDb, toDb)` 直接复用 `src/labs/niceTicks.ts` 的 `niceTicks(lo, hi)`，再把落在范围外的滤掉。`niceTicks` 自己会在 1/2/2.5/5 的十倍数里挑步长，目标是 3–9 根、尽量接近 5 根。

补了 `tests/berTicks.test.ts` 两条，测试名里写明是给 BerCurve 用的：0.5 dB 步长、41 个点时刻度 ≥4 根且首尾覆盖 0–20；`berTicks(0, 20)` 正好是 `[0, 5, 10, 15, 20]`；0–12 dB 量程是 `[0, 2.5, 5, 7.5, 10]`（2.5 步长，末根不越界）。

## 四、第三件：σ>0 时理论残余不是零
第 13 章原来读数是「剩余相位误差（实测 / 理论）」`0.000 / 0.000`，判据只看末段残差是否 `< 0.02`、`pllLockStep` 是否收敛。σ=0.1 时噪声一直在推相位，末段残余不会到零，旧写法等于把「有噪声」判成「没锁住」。

理论值：一阶环在噪声下的稳态残余 RMS 是 `σ / √(2K − K²)`，只对 `0 < K < 2` 有定义；`K ≥ 2` 时 `2K − K² ≤ 0`，环路发散，没有稳态可以报。

新增三个纯函数：`pllTheoryResidual(gain, sigma)`（σ=0 返回 0；K≥2 返回 null；否则 σ/√(2K−K²)）、`pllTheoryText`（三位小数，发散返回「发散，无稳态」）、`pllVerdict(gain, trace, sigma)`。

判定顺序是本轮返工过一次的地方：第一版先看「末 10 步比前 10 步降幅是否 >15%」，结果默认档 K=0.6、σ=0 被误判成「未收敛」——因为在 60 步内它一直按 1−K=0.4 指数下降，十步掉 60%，永远过不了 15% 这道闸。改成**先看带宽、再看下降**：

1. `K ≥ 2` → 「发散」；
2. 末 10 步均值 `tail ≤ max(3×理论, 0.02)` → 「锁住」；
3. 超带且还在降（`(prev − tail)/prev > 0.15`）→ 「未收敛」；
4. 超带但已经平了 → 「残余过大」。

读数是「末段残余（实测 / 理论）」`0.1881 / 0.320` 这种形式，hint 写明「理论值是噪声下的稳态残余 RMS，不是零」。

八格实测（`pllTrace(k, 2, σ, 20261112)`，60 步，末 10 步均值）：

| K | σ | 末段实测 | 理论 | 判定 | failed |
|---|---|---|---|---|---|
| 0.05 | 0 | 0.1881 | 0.000 | 未收敛 | true |
| 0.05 | 0.1 | 0.5312 | 0.320 | 锁住 | false |
| 0.6 | 0 | 0.0000 | 0.000 | 锁住 | false |
| 0.6 | 0.1 | 0.0571 | 0.109 | 锁住 | false |
| 1.5 | 0 | 0.0000 | 0.000 | 锁住 | false |
| 1.5 | 0.1 | 0.0913 | 0.115 | 锁住 | false |
| 2.5 | 0 | 1.1311 | 发散，无稳态 | 发散 | true |
| 2.5 | 0.1 | 1.0996 | 发散，无稳态 | 发散 | true |

K=0.05、σ=0.1 判「锁住」是因为理论值 0.320 已经把带宽撑到 0.96，末段 0.5312 落在带内——噪声大时环路本来就在带内晃，这是理论值存在的意义，不是判据松了。K=0.05、σ=0 仍是「未收敛」红，与 R40 的结论一致。

默认档（K=0.6、θ₀=2、σ=0）四条读数：`0.000 / 0.000`、`7`、`锁住`，与改前逐字相同（只改了第一条的名字）。
