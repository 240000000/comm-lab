## 二、为什么删右团是「删循环」而不是「重点阵」

点阵本身与「画几团」无关：`eyePoints.ts` 生成固定条数的眼迹采样，`formAt` 按时间在形态之间插值，投影与 12 档深度铺色都按采样点算。两团的做法是**同一套点阵画两遍、每遍只取一半迹**（`trace = zone * half` 到 `(zone + 1) * half`，`half = 30`），另一团再用 `cx = width * 0.83`、`ang = -spin + π` 镜像摆到右边。

所以删右团只需要把 `zone` 循环摊平：`trace` 从 0 走到 60、`cx` 固定到左边、`ang` 直接取 `spin`。点阵数组一次没重建，形态循环、投影、12 档深度、`syncCanvasSize` 一行没动——**总点数因此仍是 1500×2 = 3000（正好 `MAX_PARTICLES`），没有因为少画一团就翻倍**。反过来看，若改成「保留两团结构、把 `half` 提到 60」，同一套点阵会被画两遍、总计 6000 点，沉默地突破 `MAX_PARTICLES`，那才是真翻倍。
