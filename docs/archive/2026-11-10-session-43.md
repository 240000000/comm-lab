## 二、`src/course/pdfOutline.ts`：三层拆开

第一层是**纯函数**，不碰 pdf.js，测试全打在这里：

```ts
export function chapterNumberOf(rawTitle: string): number | null
export function isChapterTitle(rawTitle: string): boolean
export function chapterEntriesFromOutline(nodes: unknown): OutlineEntry[]
export function chaptersFromTextLines(lines: string[]): OutlineEntry[]
export function toBook(entries: OutlineEntry[]): OutlinedBook
```

- `chapterNumberOf` 认两种写法：`第10章　信源编码`（两位数、章号与章名之间可能是全角空格或两个半角空格）与 `Chapter 12  Orthogonal codes`；中文数字（`第十章`、`第二十一章`）先过 `chineseNumber` 再判。`4.3`、`13.2.1` 这类节级条目直接读不出章号 → 返回 null → 被过滤掉。
- `chapterEntriesFromOutline` 递归走书签树的 `title` / `items`，只留下 `isChapterTitle` 为真的条目；`dest` 不在这里解，留给第二层。
- `chaptersFromTextLines` 是兜底：书签为空时才用，按章号去重、保持出现顺序。
- `toBook` 调 `matchChapter()` 填 `topicId`；匹配不上就是 null（绝不猜），章号也读不出时才退回 `BOOK_COMMUNICATION` 的同名条目。

第二层 `parsePdfOutline` 负责 I/O：

```ts
const loadingTask = getDocument({ data })
const doc = await loadingTask.promise
const outline = await doc.getOutline()
// dest 是字符串就先 getDestination 拿数组，再 getPageIndex(target[0]) + 1
// 书签为空 → 扫前 40 页 getTextContent，把 items 里 str 拼行交给 chaptersFromTextLines
finally { await loadingTask.destroy() }
```

两个踩到的坑，都写进了文件头注释：

- pdfjs-dist 6.5.438 的 `PDFDocumentProxy` 上**没有 `destroy()`**，释放要调 `loadingTask.destroy()`；文档里写的 `doc.destroy()` 会直接 `TypeError`。
- pdf.js 会把传进去的 `ArrayBuffer` **transfer 走（detach）**，同一份 buffer 第二次解析会报 `Cannot perform Construct on a detached ArrayBuffer`，探针里每次开书都 `copy()` 切了新副本。

第三层是页码：一律 `getPageIndex(ref) + 1`，即 **PDF 页号**，界面上就写「PDF 第 N 页」。**没有**写「印刷页 = PDF 页 − 15」这种换算——那本书的正文确实从 PDF 第 16 页开始，但把这个 -15 硬编码进代码就是把某一本书的装订习惯当成规律。

## 五、独立 chunk 取证

直接拿 `src/course/pdfOutline.ts` 当 build 入口是**不行**的：app 构建会 tree-shake 掉没有任何消费方的导出，动态 `import()` 跟着一起消失，产物只剩 3.25 kB 的 KEYWORDS 表——看起来像「pdf.js 没打进来」，其实是入口整个被删了。

正确做法是造一个一定会被保留的入口（把函数挂到 `globalThis` 造成副作用），再单独构建：

```
probe-CCh9ozht.js    6.50 kB │ gzip:   2.57 kB
pdf-Bac_61Up.js    444.31 kB │ gzip: 133.68 kB
```

pdf.js 确实是独立 chunk（444.31 kB），而主包 `npm run build` 出来仍是 `index-z2OLXHfv.js` 370.21 kB——与 R66 一字不差，说明新增的东西一个字节都没进主包。两个临时文件（`src/__r67_probe.ts`、`.r67-probe.vite.config.mjs`）跑完即删，`git status` 里没有残留。
