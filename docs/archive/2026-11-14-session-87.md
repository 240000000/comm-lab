## 用户原话要点

R118 一轮做四件事：模型层改成图片直传、示例题措辞与答案改成 29.9 kbit/s、OCR 中文空格后处理、课程视图加嵌入形态。原话里的硬条件：请求体用 OpenAI 兼容多模态格式（`image_url` 放 data URL），系统提示只输出指定字段的 JSON，解析要容忍裸 JSON / ```json 包裹 / 前后有杂字三种，解析失败返回 `{ status:'error' }`，**绝不回退成演示答案**；tesseract 只用于没有端点时的离线模式与「识别出的题面」展示；`public/answer-config.json` 只放端点，仓库里绝不能出现 key；不改首页四卡、不动 13 章 compute 数据、不引新依赖。

## 这一轮要解决什么

答题模式此前只能跑内置题库：没有模型时点哪道题都是演示答案，用户看到的是「搭了架子但没有真模型」。这一轮把它变成真能作答——图片直接交给视觉模型，模型返回结构化答案，页面把耗时、token、置信度摊开给用户看；同时课程视图要能单独嵌进 iframe，供答题页右侧同屏看章节。
