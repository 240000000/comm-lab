# 拍摄单

一句话：照着这张表从上往下拍，一个镜头一行，不用临场想词。总时长 5:55（允许 5:30–6:30）。

三件事先说清楚：

- 旁白写的都是能直接念的整句，念的时候可以改一两个字，但别改成"介绍 QAM 星座"这种提示语。
- 旁白里不念代码、不念文件路径、不念网址；要用到它们的地方，用手在屏幕上点一下。
- 全片不出现"按赛规要求""根据大赛规则"这类句子，该说什么直接说事。

## 录制前检查（五项做完再按开始）

1. 浏览器缩放回到 110%：先 Ctrl 加 0 回到 100%，再按一次 Ctrl 加，正好是 110%（Chrome 的档位是 100、110、125，按两次就跳到 125 了）；或者点右下角的缩放菜单直接选 110%。录屏分辨率 1920×1080。
2. 专注助手（Windows 的"专注"）打开，通知全部关掉。
3. 麦克风在录屏软件里选中，别用默认的"混音"。
4. Xbox Game Bar 的录制音频设成"全部"（游戏 + 麦克风），不然只有画面没有声音。
5. 对着麦说三秒钟："测试一二三，测试一二三"，回放听一遍，声音清楚再开始。

窗口摆位：浏览器标签一放线上首页，标签二放存档页（字体调大到能看清），终端最小化在另一个桌面。开拍前把终端里的四条命令先粘好，别现场找。

## 出问题的时候说什么

**页面白屏**：说"页面白屏了，我刷新一下"，按 F5；十秒还是白屏，接着说"那我切到本地跑，代码是同一份"，切终端敲下面两条命令，别停录。

**数字对不上**：说"这个数和我记的不一样，我停一下"，然后把光标放到读数卡第二行，念括号里的分母："这里写的是八万个比特，所以我记的那个数是另一批样本"。当场确认，别含糊过去。

**录到一半发现说错了**：说"刚才那个说法不对，我重说一遍"，然后直接重说那一句，**不要停录、不要剪**。错的那句留在片子里，比剪掉更可信。

切本地开发的两条命令（终端里按顺序敲）：

```bash
npm ci
npm run dev
```

敲完等它打印本地地址，用浏览器打开，接着录。

## 录完自检

停录之后先别关电脑，按这三项核一遍，缺一项就重录：

1. **时长**：五到八分钟之间。片子短于五分钟直接重录；长于八分钟，先看 AI 协作段是不是超过三分钟、终端那段是不是拖太久，下一条重录时压回来。
2. **有声音**：从头跳到 0:30、2:50、5:20 三处各听两秒，三处都得有旁白，不能只有画面。Game Bar 设成"全部"之后再录，仍然要听这三处确认。
3. **分辨率**：右键文件看属性，或者播放器里看画面尺寸，要是 1920×1080。掉到 1280×720 就重录——文字会糊，评委看不清读数。

文件位置与命名：录完的文件在 `C:\Users\1\Videos\Captures`，找到最新那个 `.mp4`，重命名成 `comm-lab-演示.mp4`，再传网盘。别留在 Captures 里用默认名，过两天就分不清哪个是最终版。
